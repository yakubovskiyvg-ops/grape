# 🍇 Виноградный доктор

Бесплатная страница, которая по фото листа винограда подсказывает, чем он болен, и что с этим делать.

**Открыть:** https://yakubovskiyvg-ops.github.io/grape/

Работает прямо в браузере телефона. Фото **никуда не отправляется** — нейросеть запускается на самом телефоне. После первого открытия страница работает и без интернета.

## Как пользоваться

1. Откройте ссылку на телефоне (лучше в Chrome). Первый раз страница скачает модель — около 16 МБ.
2. Сфотографируйте **один лист крупно**, при дневном свете, без вспышки. Можно выбрать готовое фото из галереи.
3. Посмотрите ответ и советы: что делать, когда обрабатывать, какие препараты подходят.
4. Если болезнь неясна, включите режим **«Два фото: верх и низ листа»** — многие болезни лучше видны с нижней стороны.
5. На Android можно нажать **«Установить на телефон»** — появится значок, как у обычного приложения.

## Что узнаёт модель

- Милдью (ложная мучнистая роса)
- Оидиум (мучнистая роса)
- Войлочный клещ (зудень)
- Хлороз
- Здоровый лист
- «Не лист винограда» — если на фото что-то другое

Про чёрную гниль и антракноз на странице есть описание и советы, но распознавать их модель пока не умеет.

## Что ещё есть на странице

- Справочник болезней и календарь обработок по фазам развития винограда
- Калькулятор раствора (только для проверенных норм)
- Погода на 7 дней и упрощённая оценка риска милдью и оидиума
- Журнал обработок с напоминаниями (хранится только в вашем телефоне)

## Важно

- Это **подсказка, а не диагноз**. На отложенных проверочных фото модель права примерно в 3 случаях из 4. Если ответ «не уверен» или две болезни близки по вероятности — сравните признаки по таблице на странице или покажите лист агроному.
- Перед обработкой проверяйте **этикетку препарата** и его регистрацию в «Государственном каталоге пестицидов и агрохимикатов». У препаратов на странице есть пометка: разрешён ли он для личных подсобных хозяйств.
- Модель обучена в основном на чужих фотографиях. Своими снимками с участка её можно сделать точнее — для этого есть кнопка «Сохранить фото с ответом».

## Как устроено

- Нейросеть EfficientNet-B0 (PyTorch), дообученная на фото листьев винограда, переведена в формат ONNX.
- В браузере модель запускает [ONNX Runtime Web](https://github.com/microsoft/onnxruntime) (лицензия MIT).
- Работа без интернета — через service worker (`sw.js`).
